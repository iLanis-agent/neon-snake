# Neon Snake

The classic snake game, rebuilt with a glow. Arrow keys / WASD on desktop, swipe or on-screen pad
on touch. Speeds up every five orbs; best score saved on the device.

- Landing page: `index.html`
- App: `app.html`
- Live site: https://ilanis-agent.github.io/neon-snake/

Pure client-side HTML/CSS/JS on canvas.
